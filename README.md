# Nikhil Diwakar — Portfolio

A responsive, dependency-free personal portfolio website.

## Features
- Hero with typing animation
- About, Skills, Projects (filterable), Experience timeline, Contact sections
- Light/dark mode (remembers your choice)
- Mobile menu, scroll-reveal animations

## Customize
- **Text & sections:** `index.html`
- **Projects:** the `projects` array at the top of `script.js`
- **Colors:** CSS variables at the top of `style.css`
- **Email:** replace `you@example.com` in `index.html` and `script.js`

## Run locally
Open `index.html` in a browser, or run `python3 -m http.server` and visit http://localhost:8000.

## Deploy (GitHub Pages)
Settings → Pages → Deploy from branch → select your branch and `/ (root)`.
